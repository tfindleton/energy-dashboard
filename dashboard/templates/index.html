Sign In with Tesla Auth

Download the open-source Tesla Auth helper, run it with --clear-browsing-data, and complete sign-in in its native window. It captures tesla://auth/callback automatically. Copy both tokens from the same fresh result below.

Tesla requires the original access token for the first Owner API request; importing only the refresh token causes a 403. The pair is stored only in the dashboard's private auth file and is never included in an API response.
